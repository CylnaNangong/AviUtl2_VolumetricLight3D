## 1. 项目简介与核心特性

**`体積光（3D）`** 是一款专为 **AviUtl ExEdit2** 打造的**真·3D** 体积光（丁达尔效应 / God Rays）自定义对象脚本。它能够从任意图层（图像、视频、文字、图形、`@水面` 等自定义对象）的明亮区域，或直接从「摄像机控制」内的 3D 光源向三维空间发射细腻通透的体积光束，并支持真实的 2D/3D 前景遮光投影与前景环境光融合。

### ✨ 核心亮点

1. **真·3D 射线-切片体积积分（全方位自由运镜）**
   - 支持 **平行光**、**点光源放射**、**向焦点收束** 三种几何模式，100% 保留光源图层逐像素原始色彩（亦支持单色染色），具备平滑亮度阈值提取、距离衰减及内部流动的 3D 烟尘雾气扰动。
   - 体积切片自动正交对齐 3D 摄像机视线（64～192 层连续动态缩放），360° 环绕运镜或近景观察均平滑无断层，且不会令同场景的 `.obj` / `.vrm` 3D 模型出现半透明“透底”现象。

2. **2D 图层 + 3D 模型（`.obj` / `.vrm`）混合前景遮挡**
   - 支持前方 2D 图层、`テキスト`（完整兼容全部 **18 种横排/竖排文字对齐** 与 **7 种阴影/描边装饰** 的中心偏移）、标准 `.obj`「模型文件」以及 `.vrm`（`VRMToolkitModel`）在光束中投射真实的三维遮光影柱（Shadow Shafts）与无黑边前景轮廓保护。
   - 最大支持 **8 个前景遮挡物**（2D 图层 / `テキスト` 文字层上限 8 层；`.obj` / `.vrm` 3D 模型影柱独立渲染、不在此限）。

3. **单脚本内置「前景融入背景（`前景なじませ`）」3D 联动子系统**
   - 基于 **nctype** 氏开源的 [`AutoBlendLight`](https://github.com/nctype/aviutl2_script_AutoBlendLight)（MIT License）深度整合于同一 `.obj2` 内（默认关闭，按需开启，无需额外挂载 `.anm2`）。
   - 可自动或按图层区间（如 `4-5`、`3,5,7-9`）精确选定需要融合的前方 2D 图层，根据其在 3D 体积光束中的空间位置自动拾取环境色与体积光方向，生成柔和逆光包裹、清晰轮廓高光（Rim Light）与模糊背景色乘算融合，同时**自动保护更靠前的字幕、UI 与 3D 模型不受影响**。

4. **可选原生插件 `VL3DBridge.aux2`：D3D11 ComputeShader 硬件加速 + 无锁直读**
   - **GPU 硬件光栅化（`cs_5_0`）**：在 AviUtl2 `v2.1.15+` 上通过官方 SDK `EDIT_HANDLE::get_direct3d_device()` 调用 Direct3D 11 计算着色器并行渲染 3D 阴影图与相机深度图，面对数万面高模运镜或鼠标实时拖拽时提速 **20×～45×**，全程保持 100% 几何完整度不掉面。
   - **无锁只读桥接**：通过 `SCRIPT_MODULE_PARAM::edit` 实现渲染线程零加锁参数读取，彻底消除开启前景遮挡拖拽图层时的读写锁死锁，修改未保存的文本排版或场景参数无需按 `Ctrl+S` 即可实时生效。
   - **三级自动回退**：`D3D11_CS (GPU)` → `C++17 -O3 (CPU)` → `纯 LuaJIT FFI`。即使不安装 `VL3DBridge.aux2`，单靠 `体積光（3D）.obj2` 也能独立完整运行！

5. **严守 16M 缓存预算 & 8K 画幅 / 16K 超巨幅素材加固**
   - 全流程严格控制在 AviUtl2 默认 `TemporaryImageCacheSize`（1,600 万像素）与 D3D11 `4096px` 渲染目标上限之内（即使在 **8K UHD `7680×4320`** 画幅或 **5000 万像素 / 16K** 贴图下，峰值缓存仅约 `3.9M～7.2M` 像素，帧末立即缩回 `1×1` 释放）。
   - 首次打开含体积光的工程或展开次合成（サブシーン）时，自动在日志窗口输出多语言进度提示（`初始化中……` → `初始化完成`），避免首帧加载大图黑屏时被误判为卡死。

## 3. 安装方法（支持 `.au2pkg.zip` 拖入即装）

### 🚀 方式一：使用 `.au2pkg.zip` 安装包一键拖入（推荐 · 开袋即食！）

1. 前往仓库右侧的 **GitHub Releases** 页面下载最新安装包（**请勿解压**，保留 `.au2pkg.zip` 后缀）：
   - **`VolumetricLight3D-v3.07.au2pkg.zip`**（完整推荐版：含核心脚本 + `VL3DBridge.aux2` GPU 加速插件 + 四语语言包）
   - *或 `VolumetricLight3D-v3.07-ScriptOnly.au2pkg.zip`（纯脚本轻量版：仅含 `.obj2` 脚本 + 四语语言包）*
2. 打开 AviUtl ExEdit2，将下载好的 `.au2pkg.zip` 文件**直接用鼠标拖放（Drag & Drop）到 AviUtl2 预览窗口**中，在弹出的确认框点击安装即可自动部署全部文件！
3. 若包含 `VL3DBridge.aux2` 插件更新，安装后**重启一次 AviUtl2** 即可生效（日后也可随时在 AviUtl2 菜单的「包信息 / `パッケージ情報`」中一键查看或卸载）。

### 📂 方式二：手动复制散装文件夹安装

从本仓库直接下载 **`Script`**、**`Plugin`**（推荐）、**`Language`**（按需）文件夹，复制到 AviUtl2 的数据目录（默认安装通常为 `C:\ProgramData\aviutl2\`，便携版则为 `aviutl2.exe` 同级对应目录）：

```text
C:\ProgramData\aviutl2\
├── Script\
│   └── 体積光（3D）.obj2                  # [必需] 核心自定义对象脚本（v3.07）
├── Plugin\
│   ├── VL3DBridge.aux2                    # [强烈推荐/可选] 无锁读取 + D3D11 CS 硬件 3D 阴影加速插件（v1.21）
│   └── VL3DBridge.ini                     # [可选] 插件安全白名单与 GPU 开关配置（与 .aux2 同目录）
└── Language\                              # [按需选装] 多语言界面与参数悬停提示包
    ├── 简体中文.体積光（3D）.aul2         # 简体中文语言包
    ├── English.体積光（3D）.aul2          # 英语语言包
    ├── Deutsch.体積光（3D）.aul2          # 德语语言包
    └── community_de.体積光（3D）.aul2     # 德语（社区汉化前缀匹配）语言包
```

### 💡 是否安装 `VL3DBridge.aux2` 的体验对比

| 场景 / 功能 | 仅安装 `Script\体積光（3D）.obj2` | 同时安装 `Plugin\VL3DBridge.aux2`（推荐） |
| :--- | :--- | :--- |
| **纯 2D / 视频 / 文字体积光 + 前景融入背景** | 原生 HLSL GPU 渲染，帧率基本一致 | 原生 HLSL GPU 渲染 + **未保存工程实时直读文本对齐/装饰**（免按 `Ctrl+S`） |
| **高面数 `.obj` / `.vrm` 3D 模型运镜动画** | 纯 LuaJIT CPU 光栅化（高模下帧率较低） | **D3D11 `cs_5_0` GPU 硬件并行光栅化（提速 `20×～45×`）** |
| **开启前景遮挡时鼠标实时拖拽缩放图层** | 自动降分辨率 + 12ms 预算截断防卡顿（高模阴影暂时抽稀） | **零加锁防死锁 + 100% 全三角面实时完整阴影跟随** |

## 4. 快速上手与推荐图层顺序

在 AviUtl ExEdit2 中，时间轴图层**自上而下（Layer 1 → Layer N）依次渲染**。为了让体积光能够穿过前景间隙射向镜头，同时不遮盖最前方的字幕或 UI，推荐按以下顺序排列图层：

```text
Layer 1  [背景 / 光源图层]    图像、视频、文字、图形或 @水面 等（例如填在「光源图层 = 1」）
Layer 2  [前景 3D 模型]       .obj「模型文件」或 .vrm 模型（投射 3D 影柱）
Layer 3  [前景 2D 图层]       人物、插画、实拍抠像或前景道具（参与遮挡 & 可选「前景融入背景」）
Layer 4  [体積光（3D）]  ★   ← 在此添加自定义对象「体积光（3D）」，设置「光源图层 = 1」
Layer 5  [字幕 / UI 叠加层]   位于体积光图层下方（更晚绘制），保持绝对清晰、不受体积光或融合影响
```

### 三步上手：
1. 在时间轴空白图层右键 → **添加对象 → 自定义对象 → 选择 `体积光（3D）`（`体積光（3D）`）**。
2. 将 **`光源图层`** 设为发光素材所在的图层编号（如 `1`），调节 **`发射方式`**、**`光束长度`**、**`发光强度`** 与 **`亮度阈值`**。
3. 如场景中有前景物体：展开 **`前景遮挡`** 选择 `3D投影 + 前景遮挡(推荐)`；若希望前方 2D 图层自然吃光融入环境，展开 **`前景融入背景`** 勾选 **`启用前景融入背景`** 即可。

> [!NOTE]
> **⏳ 初次打开场景的加载等待提示（并非卡死！）**  
> 每次启动 AviUtl2 后**首次添加本效果、首次打开含体积光的工程，或首次切换到含体积光的次合成（サブシーン）**时，宿主需要编译全部 14 个内置 HLSL 着色器并初始化高分辨率贴图/网格管线，界面可能会短暂顿住或黑屏等待 **约 5～15 秒（高分辨率素材下通常约 10 秒左右）**。若平时未打开「日志（ログ）」窗口，只需稍等片刻即可正常出图，后续播放与调节均会恢复丝滑实时响应！

## 6. 兼容性与反编译/内存探针相关功能的失效风险说明

AviUtl ExEdit2 目前仍处于活跃迭代阶段，部分高阶宿主内部状态（例如「摄像机控制」内部的延迟渲染 3D 光源列表、编辑器自由视角“绿相机”姿态等）**尚未在官方 Plugin SDK 中提供公开读取接口**。为了实现完整的 3D 光影联动体验，本项目部分辅助能力涉及对 `aviutl2.exe`（基于 `v2.1.15` 验证）的二进制逆向分析与**只读内存探针**。

为方便用户客观评估升级风险，现将各模块的底层依赖与宿主更新影响完全公开说明如下：

| 功能模块 | 底层实现方式 | 未来 `aviutl2.exe` 更新时的风险评估 |
| :--- | :--- | :--- |
| **核心 3D 体积光渲染、Mip 预滤波、烟雾噪声**<br>**2D 前景轮廓遮挡、「前景融入背景（AutoBlendLight）」** | 100% 官方脚本 API + 原生 HLSL 像素着色器 | **极低（稳定兼容）** |
| **`VL3DBridge.aux2` 无锁图层/文本/水面/场景相机读取**<br>**`D3D11 ComputeShader (cs_5_0)` 硬件 3D 阴影光栅化** | 100% 官方 Plugin SDK（`plugin2.h` / `module2.h` `2026-10-24`） | **极低（遵循官方 SDK ABI）** |
| **「摄像机光源联动」自动读取摄像机控制内 3D 点光源/聚光灯/平行光** | 只读内存探针（读取延迟渲染 G-Buffer 光源数组） | **存在局部失效风险**：若未来宿主重构内部类内存布局，可能暂时无法检出摄像机 3D 光源 |
| **编辑器自由视角（绿相机图标）实时跟随 & 未安装 `.aux2` 时的未保存工程兜底解析** | 只读内存探针 + `.aup2` 文件解析双兜底 | **存在局部失效风险**：若偏移变化，未安装 `.aux2` 时需保存工程（`Ctrl+S`）以解析 `.obj` 路径，绿相机预览视角可能回退为正式摄像机视角 |

### 🛡️ 安全防护与自动降级机制（绝不写内存、绝不崩溃）

1. **100% 纯只读承诺**：无论是 `体積光（3D）.obj2` 还是 `VL3DBridge.aux2`，**严禁向 `aviutl2.exe` 宿主内存写入任何字节**；所有探针均通过操作系统内核级 `ReadProcessMemory` 安全拷贝，即使遇到未映射页或保护页也绝不会触发访问冲突崩溃（`Access Violation`）。
2. **PE 指纹白名单 + 机器码特征自检自动降级**：`VL3DBridge.aux2` 启动时会校验 `aviutl2.exe` 的 PE 头/`SHA-256` 白名单及机器码结构不变量。一旦未来新版 AviUtl2 内部结构发生变动导致特征不匹配，插件将**自动关闭内存探针并平滑降级为纯官方 SDK 模式**——核心体积光、2D/3D 遮挡、GPU 硬件阴影加速与前景融入背景均继续正常工作，不会损坏任何 `.aup2` 工程文件。
3. **手动强制纯白名单模式**：如果你在安全性要求极高的生产环境中使用，可随时打开 `Plugin\VL3DBridge.ini` 将 `strict_whitelist_only = 1` 开启，仅允许经过明确哈希认证的宿主版本启用只读探针。

## 7. 未来发展方向（Roadmap）

- **与同系列《体积雾（3D）》及《雪（3D）》的跨脚本三维光学联动**：打通 `VL3DBridge` 共享三维光场数据，让体积光束能够真实**照亮并染色同场的 3D 体积雾团与飘雪粒子**（例如光柱穿透浓雾时产生局部丁达尔散射增亮、雪花飘入彩色光束内部时实时染上对应光色并呈现受光高光），构成完整的三维空间大气光影体系。
- **逐步全面迁移至官方 SDK 接口**：紧跟 ＫＥＮくん 官方 Plugin SDK 的更新步伐——未来一旦官方 SDK 开放摄像机 3D 光源枚举、编辑视角相机矩阵或 3D 模型网格直接访问接口，将第一时间替换为 100% 官方 API，彻底消除对二进制特征探针的依赖。
- **更丰富的 3D 模型格式与多光源能力**：在 `VL3DBridge` 的 D3D11 计算着色器管线中扩展原生 `.glb` / `.gltf` 网格直接硬件光栅化、单图层多点光源并发投射，以及半透明彩色遮挡物（如彩色玻璃投射到三维物体表面）的透射染色阴影（Colored Transmissive Shadows）。
- **全管线 Compute Shader 体素化加速探索**：探索基于 `ID3D11Device3` 计算着色器的统一体素光束积分（Froxel / Compute Ray-Marching），进一步降低多实例与 `4K` / `8K` 超高帧率工程下的临时渲染目标带宽占用。
- **预设模板与创作工作流打磨**：补充常见光影氛围参考参数（如舞台追光、晨昏斜射光、水下焦散光束、逆光剪影等）及更多社区语言包支持。

## 9. 从源码构建 `VL3DBridge.aux2` 与打包

仓库在 [`src/VL3DBridge/`](src/VL3DBridge/) 目录下完整公开了 `VL3DBridge.aux2` 的 C++17 源码、内嵌 HLSL `cs_5_0` 着色器与跨平台整理的官方 SDK 头文件（不含任何宿主可执行文件），并在 [`packaging/`](packaging/) 下提供了 `.au2pkg.zip` 打包配置与脚本。

```bash
# 1. 使用 CMake 构建 VL3DBridge.aux2（Visual Studio MSVC 或 MinGW-w64）
cmake -S src/VL3DBridge -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

# （或使用 MinGW-w64 一键脚本构建至 Plugin/VL3DBridge.aux2）
./src/VL3DBridge/build_mingw64.sh

# 2. 生成可拖入 AviUtl2 安装的 .au2pkg.zip 发布包（输出至 dist/）
python3 packaging/build_au2pkg.py
```
