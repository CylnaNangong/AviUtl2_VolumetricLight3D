# 更新历史 — VolumetricFog3D / 体积雾（3D）

## v2.06（2026-11-02）・VL3DLF v3 体積光散乱連携

- 「散乱光源」を追加。既定の手動方向を維持しつつ、VolumetricLight3D 共有光場へ切替可能。ホストの選択項目には既定インデックス 0 を明示し、手動項目と既存プロジェクトの既定値を正しく維持。
- 霧スライスごとに 4×4 空間サンプルを行い、同一シーン・現フレームの局所光色、実際の光線方向、Band 1 投影影を取得して GPU の Henyey–Greenstein 散乱に反映。
- 有効な光場がない場合、別シーンまたは期限切れの場合は自動で手動方向へフォールバック。既存プロジェクトの既定描画は変更しない。
- `VL3DLF v3` の公式 `global` スロットのみを使用し、追加プラグイン依存なし。既存の 4 オクターブ fBm、Beer–Lambert 密度、ハードウェア Z バッファ遮蔽を維持。
