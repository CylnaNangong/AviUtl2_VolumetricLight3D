# 更新历史 — VolumetricFog3D / 体积雾（3D）

## v2.06（2026-11-02）· VL3DLF v3 体积光散射联动

- 新增「散射光来源」选项：保留旧版手动方向为默认，并可切换到 VolumetricLight3D 共享光场；显式声明宿主选择项默认索引 0，确保手动选项和旧工程默认值均正确解析。
- 联动模式将每个雾切片划分为 4×4 空间采样点，读取同场景、当前帧的局部光色、实际光线方向与 Band 1 投射阴影，再在 GPU Henyey–Greenstein 阶段进行局部散射；GPU 对光场样点双线性重建，避免最近邻采样形成块状边界。
- 暂无可用光场、跨场景或数据过期时自动回退到手动方向；不改变旧工程默认渲染路径。
- 共享光场只使用 `VL3DLF v3` 官方 `global` 槽位，不新增插件依赖；保持现有 4 层 fBm、Beer–Lambert 雾密度与硬件 Z 缓冲遮挡。
