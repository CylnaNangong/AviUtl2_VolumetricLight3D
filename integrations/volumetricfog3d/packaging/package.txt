THE REAL 3D continuous volumetric fog custom object (v2.06) for AviUtl ExEdit2.
GPU-integrated 4-octave 3D fBm noise, Beer-Lambert transmittance and
Henyey-Greenstein forward scattering with optional shared VolumetricLight3D field lighting; slices render as true 3D polygons that
interlock with the hardware depth buffer for automatic, physically correct 3D
occlusion. The preview editor viewpoint switches to a 360-degree spherical
volume automatically. v2.06: optional VL3DLF v3 link for spatial scattering direction, local light color, and projected shadows.
