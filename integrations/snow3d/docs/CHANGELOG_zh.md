# 更新历史 — Snow3D / 雪（3D）

## v1.23（2026-10-31）
- **新增「体积光联动」参数组（与 `VolumetricLight3D v3.16+` 共享真 3D 光场与遮挡阴影）**：
  - 接收同一场景内所有活动 `体积光（3D）v3.16+` 输出的 `VL3DLF v3` 光场包（`48×48` 阈值后辐射亮度与彩绘玻璃多色光、`48×48` 3D 模型/`.obj`/`.vrm` + 2D 图层光线投射阴影深度图、`48×18` 相机空间前景遮罩），严格按 `scene_id` 隔离主合成与子场景，杜绝跨场景串光与停用残光。
  - **能够被照亮 + 被遮挡就不亮**：落入体积光束内的雪花按局部光强与颜色发光（支持平行光、点光源发散光、汇聚光、摄像机 3D 聚光灯及多光源叠加）；一旦雪花沿光线进入 3D 模型或 2D 前景的阴影柱，或位于前景遮罩背后，自动切断受光并可配合「光束外与阴影压暗」呈现高对比丁达尔微尘效果（场景中无体积光时零开销、画面与 `v1.22` 逐像素完全一致）。
  - 完整支持对象自身三维旋转（`rx/ry/rz`）、中心偏移（`cx/cy/cz`）与非均匀缩放，并同时覆盖 GPU 图形贴图路径（`ps_snow_shape_tint` 多色聚类 8 级平滑亮度）与 CPU 顶点色圆形回退路径。
  - **根治 3D 摄像机控制模式下雪花柔边黑环、视角切换（编辑自由相机）同步与逆光消光（`AviUtl2 v2.1.16` 真机实测修复）**：针对 3D 摄像机通道下 `Shader #118` WBOIT 忽略 `"add"` 混合导致前景高斯柔边劫持 `Accum_w` 产生黑环的问题，新增视线后方光束重叠与深度比探测（`probe_ray_behind`）及 `ps_snow_shape_tint` 比例不变量化（`out_a = round(a * 5) / 255`）双通道 WBOIT 绘制（零额外缓存像素）；同步支持 `camera_mode == 2` 编辑相机实时基底同步、受光/遮挡粒子正负 8 元光源法线（逆光正常发亮且 3D 阴影柱内不漏光）及 `OFF / WAIT / IDLE / ON` 精细日志状态。

## v1.22（2026-10-24）
- **修复摄像机控制「目标图层＝自身」时发生区域基准漂移**：按 AviUtl2 官方规范（Default.aul2：相机位置以目标为基准），当目标偏移为 (0,0,0) 时注视点与相机坐标重合（距离 0），导致「相机跟随」启用时发生区域中心移到镜头位置、约半数粒子绕到相机背面消失、其余粒子在镜头前极端虚化。现当注视点与相机坐标一致（|target−cam|<1e-4）时，改用沿相机前方向量 f 前移焦点距 cam.d（默认 1024）的基准注视点，「目标图层＝未指定」与「目标图层＝相机自身」的粒子配置/密度/粒径/深度衰减 100% 一致。
