# 更新履歴 — Snow3D / 雪（3D）

## v1.23（2026-10-31）
- **「体積光連動」グループ新設（`VolumetricLight3D v3.16+` との真の 3D 光場・遮蔽影共有）**：
  - 同一シーン内のすべての有効な `体積光（3D）v3.16+` が出力する `VL3DLF v3` 光場パック（`48×48` 放射輝度＆ステンドグラス多色光、`48×48` 3D モデル/`.obj`/`.vrm`＋2D レイヤー投影シャドウマップ、`48×18` カメラ空間前景マスク）を `scene_id` 単位で分離受信。
  - **光が当たれば輝き、遮られれば光らない**：平行光・放射点光源・収束光・カメラ制御 3D スポットライト・複数光源の重畳に対応し、光束内の雪粒子を光色で発光させると同時に、3D/2D 遮蔽物の影柱や前景マスク背後に入った粒子は自動的に消灯（「光束外・影の減光」併用でチンダル微粒子表現にも対応。シーン内に体積光が無い場合は負荷ゼロ・`v1.22` と完全同一出力）。
  - オブジェクト自身の 3D 回転（`rx/ry/rz`）・中心ずれ（`cx/cy/cz`）・個別拡大率を含む完全なローカル→ワールド変換に対応し、GPU 図形テクスチャパス（`ps_snow_shape_tint`）と CPU フォールバック円描画パスの双方で一貫した受光表現を実現。
  - **`image-7.png`（光場共有 OFF）/ `image-8.png`（ON）の第 3 回比較を反映し、残存する黒縁をさらに修正**：旧 `probe_ray_behind` は光源軸上の有限点だけを検査し、実際の円錐境界・投影影深度・カメラ前景ホールドアウトを考慮していなかったため、光束と重なる未受光粒子を誤って非重複と判定し、通常の Shader #118 WBOIT パスへ送っていた。カメラ視線と有効光源体積の交差区間全体を扱い、軸方向 9 点＋スポット極値点を調べ、放射輝度・影深度・カメラ前景マスクを各点で検証するよう修正。光束視線上の未受光粒子は WBOIT に送らず、光束外の粒子は従来どおり描画する。
  - **受光粒子の分流と弱光時の孤立ベース描画を修正**：共有 WBOIT ベースパスは実際に受光した粒子だけに限定。安定閾値以下の受光は受光フラグも同時に解除し、対応する光晕なしの灰色ベースだけが残らないようにした。`camera_mode == 2` のライブ編集カメラ同期は維持。

## v1.22（2026-10-24）
- **カメラ制御「目標レイヤー＝自身」設定時の発生領域基準補正**：公式仕様（Default.aul2：カメラ位置は目標基準）により目標オフセット (0,0,0) で注視点とカメラ座標が一致（距離 0）となり、「カメラに追従」時に発生領域中心がレンズ位置へ移動して粒子の約半数がカメラ背面で消滅・残りがレンズ直前で極端ボケ化する問題を修正。注視点とカメラ座標が一致する場合はカメラ前方ベクトル f に沿って焦点距離 cam.d（既定 1024）だけ前方の基準注視点を用い、「目標レイヤー未指定」と「目標レイヤー＝カメラ自身」で粒子配置・密度・粒径・奥行き減衰を 100% 完全一致化。
