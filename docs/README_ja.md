## 1. 概要・主な特徴

**`体積光（3D）`** は、**AviUtl ExEdit2** 向けに設計された**真・3D ボリューメトリックライト（ボリュームライト／ゴッドレイ／薄明光線・光芒）** カスタムオブジェクトです。任意のレイヤー（画像・動画・テキスト・図形・`@水面` 等のカスタムオブジェクト）の明部、または「カメラ制御」内の 3D 光源から 3D 空間へ立体的な光の筋を伸ばし、リアルな 2D/3D 前景遮光ボリューム（影柱）と前景レイヤーの環境光ブレンドを実現します。

### ✨ 主な特徴

1. **真・3D レイ・スラブ積分による全方位ボリューメトリック描画**
   - **平行光**・**放射（点光源）**・**収束** の 3 モードに対応。光源レイヤーのピクセル単位の色彩を 100% 忠実に保持（単色オーバーライドも可）し、滑らかなしきい値抽出・距離減衰・3D 内部フォグ（煙・塵の揺らぎ）を表現します。
   - ボリュームスライスは 3D カメラ視線へ直交整列（64〜192 枚の連続動的スケーリング）するため、360° カメラワークでも段差やポップが発生せず、同シーン内の `.obj` / `.vrm` 3D モデルが半透明に透ける副作用もありません。

2. **2D レイヤー＋3D モデル（`.obj` / `.vrm`）ハイブリッド前景遮蔽**
   - 手前に配置された 2D レイヤー、`テキスト`（全 **18 種の文字揃え** と **7 種の文字装飾** の中心オフセットに完全対応）、標準 `.obj`「モデルファイル」、および `.vrm`（`VRMToolkitModel`）から、物理的な 3D 影柱（シャドウシャフト）とダークハローのない輪郭保護を生成します。
   - 最大 **8 個**の前景遮蔽物をサポート（2D レイヤー / `テキスト` 層は上限 8 層。`.obj` / `.vrm` 3D モデルの影柱は独立描画のためこの限りではありません）。

3. **単一スクリプトに「前景なじませ（AutoBlendLight 3D 連動）」を統合**
   - **nctype** 氏公開の [`AutoBlendLight`](https://github.com/nctype/aviutl2_script_AutoBlendLight)（MIT License）のアルゴリズムを `.obj2` 内に 3D 体積光連動 GPU パイプラインとして統合（既定 OFF・追加の `.anm2` 適用不要）。
   - 前方の全 2D レイヤー自動検出、またはレイヤー番号／範囲指定（例：`4-5`, `3,5,7-9`）に対応。3D 光束内の空間位置に応じて背景色・体積光色を自動抽出し、逆光グラデーション・輪郭リムハイライト・環境乗算ブレンドを適用します（より手前にある字幕・UI・3D モデルは自動的にホールドアウト保護されます）。

4. **補助プラグイン `VL3DBridge.aux2`：D3D11 ComputeShader 高速化＋無ロック直読（任意併用）**
   - **GPU ハードウェアラスタライザ（`cs_5_0`）**：AviUtl2 `v2.1.15+` の公式 SDK `EDIT_HANDLE::get_direct3d_device()` を通じて Direct3D 11 コンピュートシェーダで 3D 影マップとカメラ深度マップを並列描画。数万ポリゴンの高精細モデルでも **20〜45 倍高速** に動作し、マウスドラッグ中も間引きなし（100% 全ポリゴン）でリアルタイム追従します。
   - **無ロック読取ブリッジ**：`SCRIPT_MODULE_PARAM::edit` により描画スレッドからロックなしでパラメータを取得。前景遮蔽オン時のドラッグ編集デッドロックを解消し、未保存（`Ctrl+S` 前）のテキスト揃え変更等も即座に反映します。
   - **3 段自動フォールバック**：`D3D11_CS (GPU)` → `C++17 -O3 (CPU)` → `純 LuaJIT FFI`。`VL3DBridge.aux2` を導入しない環境でも、`体積光（3D）.obj2` 単体で全機能が動作します。

5. **1,600 万ドット予算厳守 ＆ 8K キャンバス／16K 超大素材への耐性**
   - AviUtl2 標準の `TemporaryImageCacheSize`（1,600 万ドット）および D3D11 `4096px` RTV 制限内で厳密に動作（**8K UHD `7680×4320`** 画面や **5,000 万画素／16K** 素材でもライブキャッシュ頂点は約 `3.9M〜7.2M` ドット、フレーム終了時に即時 `1×1` 解放）。
   - 初回読み込みやサブシーン展開時には、ログウィンドウへ `初期化中……` → `初期化完了` を自動通知し、大容量テクスチャ読込中の黒画面待機がフリーズと誤認されるのを防ぎます。

## 3. 導入方法（`.au2pkg.zip` D&D インストール対応）

### 🚀 方法 1：`.au2pkg.zip` パッケージをプレビュー画面へドラッグ＆ドロップ（推奨・一番簡単！）

1. **GitHub Releases** から最新版パッケージをダウンロードします（**解凍せずそのまま**使用します）：
   - **`VolumetricLight3D-v3.10.au2pkg.zip`**（フル推奨版：本体スクリプト ＋ `VL3DBridge.aux2` GPU 高速化プラグイン ＋ 多言語パック）
   - *または `VolumetricLight3D-v3.10-ScriptOnly.au2pkg.zip`（スクリプト単体版：`.obj2` ＋ 多言語パックのみ）*
2. AviUtl ExEdit2 を起動し、ダウンロードした `.au2pkg.zip` を **プレビュー画面へ直接ドラッグ＆ドロップ** すると確認ダイアログが表示され、一括で自動インストールされます。
3. `VL3DBridge.aux2` を含む場合は、インストール後に **AviUtl2 を一度再起動** してください（導入後は AviUtl2 の「パッケージ情報」から確認・ワンクリック削除も可能です）。

### 📂 方法 2：手動でフォルダへ配置する場合

リポジトリ内の **`Script`**、**`Plugin`**（推奨）、**`Language`**（任意）フォルダを AviUtl2 のデータフォルダ（通常は `C:\ProgramData\aviutl2\`、ポータブル構成の場合は `aviutl2.exe` と同階層の各フォルダ）へ配置してください。

```text
C:\ProgramData\aviutl2\
├── Script\
│   └── 体積光（3D）.obj2                  # [必須] カスタムオブジェクト本体（v3.10）
├── Plugin\
│   ├── VL3DBridge.aux2                    # [推奨/任意] 無ロック読取＋D3D11 CS 3D影高速化プラグイン（v1.21）
│   └── VL3DBridge.ini                     # [任意] 安全ホワイトリスト・GPU設定ファイル（.aux2 と同フォルダ）
└── Language\                              # [任意] 多言語パック（日本語環境では不要・標準内蔵）
    ├── 简体中文.体積光（3D）.aul2
    ├── English.体積光（3D）.aul2
    ├── Deutsch.体積光（3D）.aul2
    └── community_de.体積光（3D）.aul2
```

### 💡 `VL3DBridge.aux2` 併用有無の比較

| 用途・シーン | `Script\体積光（3D）.obj2` 単体 | `Plugin\VL3DBridge.aux2` 併用（推奨） |
| :--- | :--- | :--- |
| **2D 画像・動画・テキスト光源＋前景なじませ** | ホスト HLSL GPU 描画で同等の高速動作 | 同左 ＋ **未保存時のテキスト揃え・装飾オフセット即時追従**（`Ctrl+S` 不要） |
| **高ポリゴン `.obj` / `.vrm` のカメラアニメ** | 純 LuaJIT CPU ラスタライズ（高ポリゴン時は負荷大） | **D3D11 `cs_5_0` GPU 並列ラスタライズ（`20〜45倍` 高速）** |

## 4. 基本的な使い方・推奨レイヤー順

AviUtl ExEdit2 では、タイムラインの **上のレイヤーから順（Layer 1 → Layer N）に描画** されます。前方の隙間から手前へ差し込む光条を描画しつつ、最前面の字幕や UI に光が被らないようにするため、以下のレイヤー順を推奨します。

```text
Layer 1  [背景・光源レイヤー]   画像・動画・テキスト・図形・@水面 など（例：「光源レイヤー = 1」）
Layer 2  [前景 3D モデル]       .obj「モデルファイル」や .vrm モデル（3D 影柱を落とす対象）
Layer 3  [前景 2D レイヤー]     立ち絵・イラスト・実写切り抜き・小物等（遮蔽 ＆ 任意の「前景なじませ」対象）
Layer 4  [体積光（3D）]    ★   ← ここにカスタムオブジェクト「体積光（3D）」を配置し、「光源レイヤー = 1」を指定
Layer 5  [字幕・UI レイヤー]    体積光より下段に置くことで、光束やなじませの影響を受けずくっきり表示されます
```

> [!NOTE]
> **⏳ 初回読み込み時の待機時間について（フリーズではありません！）**  
> AviUtl2 起動後に**初めて本オブジェクトを配置した際や、体積光を含むプロジェクト／サブシーンを初めて開いた際**は、全 14 種の内蔵 HLSL シェーダのコンパイルおよび高解像度テクスチャ・3D メッシュの初期化が行われるため、**約 5〜15 秒（高解像度素材では 10 秒前後）** プレビューが待機状態になることがあります。「ログ」ウィンドウを閉じて作業している場合もフリーズではありませんので、そのまま少しお待ちください（初期化完了後はスムーズにリアルタイム動作します）。

## 6. 内部構造依存機能（逆アセンブル／メモリ読取）の将来非互換リスクについて

AviUtl ExEdit2 は現在も活発に更新が続けられており、一部のホスト内部情報（「カメラ制御」内の遅延シェーディング 3D 光源配列や、編集用自由視点［緑カメラ］のリアルタイム姿勢など）については、**現時点の公式 Plugin SDK に取得用 API がまだ用意されていません**。そのため、本プロジェクトの一部の補助機能では `aviutl2.exe`（`v2.1.15` にて検証）のバイナリ解析に基づく **読み取り専用メモリプローブ** を併用しています。

将来の本体アップデートに伴う影響範囲を以下の通り明確に公開します：

| 機能モジュール | 実装方式 | 将来の `aviutl2.exe` 更新時のリスク評価 |
| :--- | :--- | :--- |
| **基本 3D 体積光描画・ミップ処理・3D 霧ノイズ**<br>**2D 前景シルエット遮蔽・「前景なじませ（AutoBlendLight）」** | 100% 公式スクリプト API ＋ HLSL ピクセルシェーダ | **極めて低い（安定動作）** |
| **`VL3DBridge.aux2` 無ロックレイヤー／テキスト／水面／カメラ読取**<br>**`D3D11 ComputeShader (cs_5_0)` ハードウェア 3D 影ラスタライズ** | 100% 公式 Plugin SDK（`plugin2.h` / `module2.h` `2026-10-24`） | **極めて低い（公式 SDK ABI 準拠）** |
| **「カメラ光源連携」によるカメラ制御内 3D 光源（点光源等）の自動検出** | 読み取り専用メモリプローブ（G-Buffer 光源配列の参照） | **一部機能停止の可能性あり**：内部構造変更時、カメラ内 3D 光源の自動追従・検出が一時的に無効化される場合があります |
| **編集用視点（緑カメラアイコン）追従 ＆ `.aux2` 未導入時の未保存シーン補完** | 読み取り専用メモリプローブ ＋ `.aup2` 解析フォールバック | **一部機能停止の可能性あり**：オフセット変更時、緑カメラ視点追従や `.aux2` なしでの未保存 `.obj` 検出がフォールバック動作になります |

### 🛡️ 安全設計と自動フォールバック保証（メモリ書き換えゼロ・クラッシュ防止）

1. **ホストメモリへの書き込みは一切行いません**：`体積光（3D）.obj2` および `VL3DBridge.aux2` は **100% 読み取り専用** であり、OS カーネル経由の `ReadProcessMemory` のみを使用します。未マップ領域等によるアクセス違反クラッシュは発生しません。
2. **PE フィンガープリント＆機械語シグネチャ検証による安全な自動縮退**：将来の AviUtl2 更新で内部レイアウトが変化しシグネチャが一致しなくなった場合、`VL3DBridge.aux2` は**自動的にメモリプローブを遮断して「純公式 SDK モード」へ移行**します。プロジェクト（`.aup2`）の破損やクラッシュを起こすことなく、体積光描画・2D/3D 遮蔽・GPU `cs_5_0` 高速化・前景なじませはそのまま継続して利用可能です。
3. **厳格ホワイトリストモード**：`Plugin\VL3DBridge.ini` にて `strict_whitelist_only = 1` を設定することで、SHA-256 が明示的に許可された本体ビルド以外でのプローブを完全に無効化することも可能です。

## 7. 今後の展望（ロードマップ）

- **同シリーズ「体積霧（3D）」「雪（3D）」との 3D 光学連動**：`VL3DBridge` を介して 3D ライトフィールドを共有し、**体積光で同シーン内の 3D 体積霧を局所的に照らし出したり、光束の中を舞う雪粒子を光の色でリアルタイムに染めたりする**クロススクリプト連携を予定しています。
- **公式 Plugin SDK API への段階的完全移行**：今後 ＫＥＮくん氏による公式 Plugin SDK でカメラ制御 3D 光源や編集視点・3D メッシュ取得 API が公開された際には、速やかに公式 API へ置き換え、バイナリ構造依存をゼロにしていきます。
- **対応 3D 形式とマルチライト表現の拡張**：`VL3DBridge` の D3D11 ComputeShader パイプラインにおける `.glb` / `.gltf` 直接ラスタライズ対応、複数 3D 光源の同時放射、および半透明カラー遮蔽物（ステンドグラス等の色付き透過影）表現の強化。
- **フル ComputeShader ボリューム積分パイプラインの探求**：`ID3D11Device3` コンピュートシェーダを活用した統合レイマーチング／フロクセル化により、`4K` / `8K` 高フレームレート編集時のキャッシュ帯域をさらに削減。
- **プリセット拡充・ワークフロー改善**：舞台スポットライト・斜光・水中コースティクス等のプリセット整備および多言語対応の継続改善。

## 9. `VL3DBridge.aux2` のソースビルドとパッケージ生成

[`src/VL3DBridge/`](../src/VL3DBridge/) に全 C++17 ソース・組込 HLSL `cs_5_0` シェーダ・公式 SDK ヘッダを、[`packaging/`](../packaging/) に `.au2pkg.zip` 生成スクリプトを収録しています（`aviutl2.exe` 等の本体バイナリは一切含みません）。

```bash
# 1. CMake ビルド（MSVC または MinGW-w64）
cmake -S src/VL3DBridge -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

# （または MinGW-w64 ビルドスクリプト）
./src/VL3DBridge/build_mingw64.sh

# 2. D&D 導入用 .au2pkg.zip パッケージの生成（dist/ へ出力）
python3 packaging/build_au2pkg.py
```
