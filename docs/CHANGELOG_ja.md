# 更新履歴 — 体積光（3D） / VL3DBridge

## v3.07（2026-10-25）
- **「カメラ光源に追従」時のカメラ制御ライト「明るさ」逆転現象およびスポット光源「範囲」不連続ジャンプ不具合の修正**
  - **ホスト `CameraLight64`（`aviutl2.exe` 内部構造体）フィールド仕様の厳密整合**：
    - `float[1..3]` が被照射点→光源への単位ベクトル `L = normalize(P_light - P_target)`（光線進行方向は `-float[1..3]`）であることを反映し、スポット光源・平行光源の射出向きが逆転していた問題を修正。
    - `float[15]` がスポット内錐半角ラジアン `範囲 * pi / 180`（`0..pi/2`）であることを反映し、従来の `acos(f[15])` 誤適用および `範囲 > 57.3°`（`1 rad` 超）や `< 2.9°` でフォールバック角へ急変していた不連続ジャンプを根治。公式 `obj.getvalue` でスポット光源の `ぼかし`・点／スポット光源の `減衰` も取得し、`0°..90°` 全域で連続変化（`明るさ = 0%` またはスポット `範囲 + ぼかし = 0°` 時は完全消灯）するよう修正。
    - 仮想開口を従来の `120px` 先の正方形パッチから `3px` 先のアンチエイリアス円形／放射状開口へ変更し、狭角スポット時の根元 `120px` 空白ギャップと四角形断面アーティファクトを解消。
  - **点光源・スポット光源・平行光源すべてで「明るさ」を上げるほど体積光が暗くなっていた逆転現象の根治**：
    - AviUtl2 ホスト 3D OIT シェーダー（`Shader #118`）がスライス多角形へ `unlit_mul + amb + cl_rgb * Cone * Atten * max(0, N·L)`（`unlit_mul = clamp(1 - 明るさ/100, 0, 1)`）を乗算する仕様に対し、公式 `obj.drawpoly({x,y,z,u,v,vx,vy,vz}, 4, alpha)` の頂点法線指定（点・スポット光源では光源投影点基準の適応共有ノード格子により全スライスで `N·L ≈ 1.0` を維持）と `beamatlas` 内のピクセル単位 RGB ホスト照明補償を導入し、`0%..200%` 全域で明るさに正比例して単調増加（`100%` 超の高輝度領域も自然に増光）するよう修正。

## v3.06（2026-10-24）
- **特定のレイヤー構成で前景遮蔽影が「矩形黒塊・輪郭崩れ・点滅」になる不具合の修正**
  - 遮蔽マスクの「シルエット監査」`audit_object_alpha()` を追加：効果付き読み込み（`obj.load("layer", no, true)`、公式ドキュメントがエフェクト側描画時の不定挙動を注意喚起）がほぼ全面不透明のベタ矩形（α カバレッジ ≥ 98.5%）を返した場合、効果なし生ロードへ自動フォールバックして良い方を採用し、矩形黒塊影を根治。監査は `getpixeldata` 疎格子サンプリング（≤64x64 点・`pcall` 完全防護・非対応環境では自動スキップ）で定常コストほぼゼロ。
  - HUD 自己診断：遮蔽表示に `,opq`（マスクほぼ全面不透明）と `L4*`（生ロードへフォールバック済み）マークを追加。
  - `occ2d` ドラッグキャッシュキーへ読み込みモード（fx/raw）を反映し復元前に事前スタンプ、点滅を防止。
  - 14 段の HLSL シェーダーは 0 変更（バイト級一致）。健全レイヤーの描画結果は `v3.05` と完全一致（`max_rgba_diff=0`、`frame_s=0` / `frame_s=619` 両検証）。

## v3.05（2026-10-24）
- **非 0 フレーム開始クリップおよびサブシーンにおける前景遮蔽 `0hit` 不具合の修正**
  - 公式 API `obj.frame_s + obj.frame`（シーンチェンジ延長時は `obj.frame_e` クランプ）に基づくシーン全体基準フレーム関数 `vl_scene_frame()` を導入し、クリップがタイムライン先頭（0 フレーム）以降に配置されている場合（`obj.frame_s > 0`）に従来の `obj.frame` がクリップ開始前の空区間を参照して全レイヤーを `"EMPTY"`（`遮蔽=0hit`）と誤判定していた問題を根治（前景遮蔽・前景なじませ・テキスト光源文字揃え・カメラ制御・水面色取得の全 7 箇所を統一）。
  - `obj.scene_id` によるサブシーン（`シーン` オブジェクト経由描画）のシーン一致検証および組み込み `テキスト` 18 種文字揃えの公式 `obj.getvalue(layer, ...)` 直接取得フォールバックを追加。

## v3.04（2026-10-24）
- **実機 `D3DCompile` 警告昇格エラー（`X3129` / `X3556`）の修正**
  - AviUtl ExEdit2 本体の `Media::ShaderCompile::compileFromMemory()`（`D3DCOMPILE_WARNINGS_ARE_ERRORS` 有効）において、`ps_vl_pool` / `ps_vl_prep` の階層ストライド計算に含まれていた符号付き整数除算（`/ 32`, `/ 16`）が FXC 警告 `X3556` → エラー `X3129` となりシェーダ読込が失敗していた不具合を、丸め誤差ゼロの 2 の負べき乗乗算（`ceil(p0.z * 0.03125)`, `ceil(p0.z * 0.0625)`）へ置換して根治。
