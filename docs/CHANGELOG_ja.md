# 更新履歴 — 体積光（3D） / VL3DBridge

## v3.14（2026-10-28）
- **非スポット経路（2D レイヤー／点光源／平行光）の光束亮度が v3.06（README デモ版）より約 4%〜9% 暗くなる問題を修正**
  - **根因**：`v3.08` がスポットコーンの WBOIT 年輪環根治のために導入した比例 Alpha 符号化（`wboit_ka = 0.24`）と着色器内 `ka_eff = max(0.24, min_a*2.4/core_emit)` boost 項により、非スポット経路のスライス alpha が発光量に比例し、切片スタック総不透明度（veil）が v3.06 の定数 alpha トークンの約 2 倍（数字孪生実測 `0.198` vs `0.096`）に膨張。宿主 OIT 合成での自己減衰＋背景追加遮蔽として光束全体の暗化として顕在化（黒背景で約 −4.5%、亮い背景上で最大 −0.075 画素値）。
  - **導入経緯**：比例 Alpha は宿主 WBOIT 深度重み下で全スライスの Straight 色比 `r4.rgb / r4.w` を一定に保ち、年輪環と灰色煙 veil を根治するためのもの（v3.08 / v3.09 参照）。ただしスポット経路は `v3.12` ですでに「定数 alpha＋色比カラー」（`wboit_ka = 0`、`min_opt_a = 4/255`）へ回帰済みで、非スポット経路のみ v3.08 方式が残っていた。
  - **修正**：非スポット経路を定数 alpha トークンへ復元（`wboit_ka = 0` → 着色器内 `out_a = p12.z`）。v3.06 および v3.12+ スポット経路と一致。数字孪生で亮度比 `0.95〜1.00×`（修正前 `0.91〜0.96×`）へ回復、veil も v3.06 水準へ。v3.09〜v3.12 のスポット修復への影響なし。ロールバックは `wboit_ka = 0.24` の 1 行。
  - **再現／検証**：`python3 analysis/beam_brightness_twin.py`（GPU / AviUtl2 不要、各版の亮度比・背景結合・アブレーションを出力）。
- **補足（回归ではなく想定動作）**：`v3.07` の逐ピクセル宿主照明逆補償は `saturate(1/H)` で截断されるため、宿主照明 `H > 1`（カメラ制御「発光度」> 100% または環境光／複数ライト）のシーンでは光束が設計放射亮度に上限付けされます（v3.06 は `H` を额外に乗算していたためより明るい）。旧プロジェクトで発光度 > 100% の場合、新版は `1/H` だけ暗く見えます —— 旧観感が必要なら発光度を 100% に戻すか「強度」を比例上昇してください。

## v3.13（2026-10-26）
- **3D カメラ／編集カメラ下で「画面に状態表示（HUD）」が表示されなくなっていた不具合を修正**
  - **原因特定**：`v3.12` で HUD 自身の影焼き込みを防ぐため `z_cam = 32`（`k_hud = 32 / focal_d`）へ配置した際、AviUtl / ExEdit2 の 3D カメラ透視投影における近クリップ面 `zn`（`約 102.4〜128`）より手前に入ったため、D3D11 視錐台クリッピングによって HUD ビルボード全体が破棄されていた。
  - **視錐台セーフ近傍投影（`z_hud = max(256, focal_d × 0.28125)`）**：3D 透視カメラ有効時の投影距離を `z_hud = max(256, focal_d × 0.28125)`（標準 `focal_d = 1024` で `z_hud = 288`, `k_hud = 0.28125`；近距離の影付きスポット光源 `z_lp > 220` がある場合は `min(z_hud, max(192, z_lp × 0.72))` へ自動追従）に刷新。近クリップ面 `zn` より十分奥で鮮明に表示されつつ、シーン内の光源や 3D モデルより十分手前（スポット光円錐外）に保たれるため、HUD による横縞影焼き込みゼロもそのまま両立。
- **動画出力（エンコード書き出し）時の HUD・診断案内テキスト自動非表示化（`obj.getoption("gui")` 連動）**
  - AviUtl ExEdit2 公式 Lua 仕様 `obj.getoption("gui")`（編集プレビュー中は `true`、動画出力中は自動的に `false`）で状態 HUD・遮蔽未選択ヒント・光源未選択バナーを一括ゲート。「画面に状態表示」を ON にしたまま動画書き出しを行っても、最終出力ファイルには HUD 文字が一切焼き込まれないよう安全化。

  - **4 段階ベース不透明度（`min_opt_a = 4/255`, `poly_alpha = 0.064125`）とスライス位相コヒーレント生存**：`v3.11`（`min_opt_a = 1/255`, `poly_alpha = 0.2565`）では `scaled_sp × 255` が最小量子化 1 段の境界（`0.6〜1.3`）付近に位置していたため、`scaled_sp × 255 < 1.0` の領域で 2D R2 空間ディザが一部テクセルを `(0,0,0,0)` に落とすと、ハードウェア `2×2` バイリニア補間で隣接 3 テクセルの `r4.w` も `0.75 × 0.001006 < 0.001` へ低下して一括 `discard` され（生存率 `p` が `p⁴` に急落）、`1 / h_est` で `>= 1.0` を維持する左右の半影帯 `[R - B/2, R + B/2]` とピーク距離付近のみが中空の馬蹄形アーチとして浮き上がっていた。`v3.12` では外縁ゼロ隣接 `r4.w = 0.001006` ハードウェア破棄を維持したまま内部階調を 4 倍高精細化して `p⁴` クリフと黒点スペックルを根絶し、極低輝度域（`s255 < 4`）では黄金比スライス位相コヒーレント生存＋`C_slice >= H_host` 補償へ自動切替して白い床面の暗化ゼロ（`255/255` 維持）を両立。
  - **解析的「視線 ∩ 光円錐 ∩ 終端球 `L_tot` ∩ 前景遮蔽面」6 点弦積分**：斜め照射時（`X = +1110` / `-990` 等）、同一カメラ視線上で手前コーン壁の `||wp - LP||` が奥のコアより先に `長さ` 終端減衰域へ入るため、スライス局所評価では `w(z) = exp(-0.085z)` が手前壁の減衰値のみを拾って光束を横断する円弧状境界線を生じていた。カメラ視線と円錐・球 `L_tot`・前景遮蔽面の解析的交差区間 `[s_c0, s_c1]` 上の 6 点中点積分で軸減衰・距離減衰・角度包絡を一括評価（`shell_cull` 撤廃）し、同一視線上の全スライスで Straight 色比 `r4.rgb / r4.w` を一致させて WBOIT 深度重みバイアスを完全打消し（あわせて編集視点フォールバック時の 2D 前景マスク視線方向 `-p8` → `-p2` を修正。点光源・平行光源・2D 光源パスは完全不変）。

## v3.11（2026-10-26）

  - **`read_cam_light_fx_extras()` がカメラ制御レイヤーや回転制御下で常に `ぼかし = 0°` を返していた 3 つの原因を修正**：
    1. `カメラ制御` レイヤーは通常メディアオブジェクトを持たないため `obj.getvalue("layer"..ln)` が常に `false` を返し、全レイヤーが事前スキップされていた問題；

    3. `scan_aul2_translations()` にカメラ光源名・項目名の多言語辞書が未登録だった問題。`layerN` 事前ゲートと距離上限を廃止し、`rad(範囲 + 0.5×ぼかし)` と `cl.cos_ang` の角度一致＋明るさ一致を主スコア（距離は微小タイブレークのみ）として `.aul2` 自動走査・`pcall` 保護付きで取得するよう刷新。
  - **ホスト `Shader #118` 余弦空間コーン減衰への厳密整合 ＋ 視線適応型ナイキスト接線シェル ＋ 非減衰 R2 準乱数ディザ**：
    - 体積光 OFF 実機画像との画素フィット検証（`RMSE = 0.89/255`）により、ホスト `CameraLight64.f[15]` は `rad(範囲 + 0.5×ぼかし)` を保持し、`Shader #118` は余弦空間 `smoothstep(cos(R + B/2), cos(max(0, R - B/2)), cos(θ))` を乗算すること、さらに WBOIT の急峻な深度重みにより最前面スライス 1 枚が `Accum` の約 8 割を占めることを確認。
    - 狭〜中程度の `ぼかし` で手前スライスが半影帯 `[R - B/2, R + B/2]` を横切る際に `beamatlas` テクセルのナイキスト限界を超えて生じていた鋸歯状リングに対し、**視線適応型ナイキスト接線シェル（Ray-Adaptive Nyquist Shell）** を導入。狭角ぼかしでは内部視線の手前・奥半影皮膜をコア境界 `R - B/2` で除去して `H_host ≡ const`（`ぼかし = 0` と同等の完全無段差）を保証しつつ外縁視線では滑らかな接線シェルを維持し、広角ぼかしでは `R + B/2` へ連続開放。
    - 単一階段アルファ `min_opt_a = 1/255`（`poly_alpha = 0.2565`, `cam_comp = 0.48`）により外縁ゼロ隣接バイリニア漏れの `99.4%` をハードウェア破棄しつつ Straight 輝度 `C_i = r4.rgb / r4.w >= Bg` を維持して `v3.10`（`min_opt_a = 6/255`）で生じていた白い床面の暗化（`244 → 165`）を解消。さらに非減衰 `[0, 1)` 2D R2 低食い違い列＋黄金比スライス位相ディザにより `2×2` バイリニア 4 頂点で実効 10-bit 階調を実現。

  - ホスト `CameraLight64.ltype` の全列挙値（`0`=環境光、`1`=平行光源［影 OFF］、`2`=平行光源［影 ON］、`3`=点光源、`4`=スポット光源［影 OFF］、`5`=スポット光源［影 ON］）を確認。従来は `ltype == 5`／`ltype == 2` のみを判定していたため、「影を付ける」を外すとスポット光源（`ltype = 4`）が固定 `48°` の点光源フォールバックへ落ちて「範囲」「ぼかし」が効かなくなっていた。Lua 側の仮想光源・コーン角取得・法線格子および HLSL `ps_vl_beamatlas` の全 20 箇所を `ltype = 4/5`・`ltype = 1/2` へ完全対応させ、「影を付ける」の ON/OFF に関わらず同一のコーン角度・ぼかし追従を実現。

## v3.10（2026-10-26）
- **スポット光源（カメラ制御）コーン内部に残存していた瓦状スライス段差および 3D 遮蔽影壁の階段ジャギーを完全根治**
  - **ホスト側スポット光源の厳密角度仕様 `[max(0, 範囲 - ぼかし), 範囲]` への整合**：実機「範囲／ぼかし」比較検証と `aviutl2.exe` ホスト `Shader #118`（`0x1404404b0`）逆解析により、ホストの「範囲」は外縁カットオフ半角 `θ_outer` であり、「ぼかし」は内側への減衰幅 `θ_inner = max(0, 範囲 - ぼかし)`（`範囲 = 0` のときは `ぼかし > 0` でも完全消灯）であることを確定。従来の `v3.07`〜`v3.09` は外側拡張 `[範囲, 範囲 + ぼかし]` として扱っていたため、`[範囲 - ぼかし, 範囲]` 帯で `beamatlas` が満輝度 `1.0` 前提で逆除算する一方ホストは `unlit` へ減衰し、さらにホストが既にゼロとなる `[範囲, 範囲 + ぼかし]` 外帯へもスライスを出力していた。カメラ視線が深度重み `w(z)` の大きい手前側コーン前壁でこの不整合帯を横切ることで、コーン内部全面に周期的なU字瓦状スライス段差が投影されていた問題を根治。
  - **6 段階マルチレベルアルファ符号化（`k_ref = 6`, `min_opt_a = 6/255`, `poly_alpha = 0.2565`）と WBOIT 比不変スケーリング**：`v3.09` の単一階段 `out_a = 1/255` では `r4.w = 0.001006` となるため、コーン内部の 3D 遮蔽影壁や半テクセル境界で隣接テクセルが `0` になるとバイリニア補間遷移域の `99.4%` がホストの `r4.w < 0.001` で破棄され、`4×5 px` のブロック状階段ジャギーが生じていた。`v3.10` では最小非ゼロ段階 `k = 1`（`r4.w = 0.001006`）でコーン外ゼロ背景への漏れ出し阻止を維持しつつ、内部フル被覆テクセルを `k = 6` へ引き上げてバイリニア遷移域の `83%` を保持。`raw_div * (k_out / k_ref)` による WBOIT Straight 色比 `r4.rgb / r4.w` 保存、12 サブステップ 3D Hann コーン×影被覆率積分、斜め縞を生まない R2 低食い違い列＋黄金比スライスディザにより、`明るさ = 0%..200%`・`ぼかし = 0°..90°` 全域で段差ゼロの滑らかな光束を実現（点光源・平行光源・2D レイヤー光源の挙動は `v3.08` から完全不変）。
- **初回プロジェクト読込時のログ「初期化完了（0.00秒）」が常に `0.00` 秒となる時計基準切替バグの修正**
  - 原因：初回オープン時、`VL3DBridge.aux2` ロード前に呼ばれる `detect_ui_lang()`／`vl_bf_prepare()` の `vl_wall_time_sec()` は Win32 `QueryPerformanceCounter`（PC 起動からの経過秒数、例：`45123.45 s`）を `_init_t0` に記録していた一方、`vl_bf_prepare()` 途中で `obj.module("VL3DBridge")` がロードされると `vl_bf_render()` 完了時の `vl_wall_time_sec()` が `bridge_mod.wall_time_sec()`（C++ `ModWallTimeSec` 内の遅延 `static t0 ≈ 0.00 s` 基準）へ切り替わり、差が負となって `math.max(0.0, ...)` で `0.00` 秒にクランプされていた（2 回目以降は `bridge_mod` が `_VL_PERSIST` に常駐済みのため正常表示）。
  - `vl_wall_time_sec()` を初回呼び出し時に `_VL_PERSIST.clock_state` へ単一モノトニック時計としてロックする設計（`int64_t` QPC 差分計算＋単調増加保証＋`_VL_PERSIST.init_t0_map` によるフレーム跨ぎリトライ保持＋POSIX `ffi_l` 修正）へ統一し、初回オープン時も `VL3DBridge.aux2` ロード時間を含む正確な初期化所要秒数を出力するよう修正。

## v3.08（2026-10-25）

  - AviUtl ExEdit2 本体の 3D OIT（Weight-Blended OIT, `Shader #118`）が指数型の深度重み `w(z)` を伴う重み付き平均で合成される仕様に対し、従来は全スライスへ定数アルファ `out_a = 1/255` を出力していたため、手前側の光錐境界とスライス平面の交線 `sf = zc_front / dz` が整数を跨ぐたびに微弱な外縁スライスが奥のコア輝度を約 28% 引き下げて鋸歯状の年輪段差を生んでいたこと、また `beamatlas` のホスト減光補償 `phi_h` が 12 サブステップ窓の外側（単一点 `wp0`）で評価され小ぼかし角（`1°` 前後）でスライス間の重なりを切断していたことを特定。
  - 適応 `poly_alpha`（`0.045..0.27`）と灰色煙ベールを生まない発光量比例アルファ符号化（`wboit_ka = 0.24`、コーン中心から外縁まで全スライスの Straight 色比 `r4.rgb / r4.w` を深度重み不変に整合）を導入し、さらに `phi_h` の 12 サブステップ余弦窓積分と仮想スポット円形開口の 12% 余白確保により、鋭いスポット（`ぼかし 0°..1°`）から広角ソフトコーンまで段差ゼロの滑らかな連続描画を実現。
- **点光源等の広角光束における 3D モデル遮蔽時の砂状スペックルノイズおよび終端キャップ段差の根治**
  - 広角コーンで 1 `beamatlas` テクセルが `g_shmap`（`1280×1280`）上で `7..10` テクセル分に拡大投影される際、`影のぼかし = 0` で単一点サンプルとなりナイキスト折り返しが生じていた問題と、PCG 白色乱数位相が薄い花弁・茎の影シートで隣接テクセル間の明滅ノイズを生んでいた問題を解消。
  - `beamatlas` テクセルの解析的シャドウマップ・ヤコビアン `(du_sh, dv_sh)` に基づく異方性フットプリントフィルタ（偶奇サブステップ交互 45° 回転による実効 9 タップ被覆）と低分散黄金比スライス層化により、`影のぼかし = 0` でも微細シルエットの影柱を滑らかかつシャープに描画。
- **編集視点（俯瞰カメラ）切替時のライブ追従フォールバック修正**
  - `VL3DBridge.ini` の既定設定（`allow_rpm = 0`）時に `try_read_live_edit_camera()` が誤ってタイムライン側の `get_scene_camera` へフォールバックしていた分岐を除去し、LuaJIT FFI ライブ編集カメラ読取が正常に機能するよう修正。

## v3.07（2026-10-25）
- **「カメラ光源に追従」時のカメラ制御ライト「明るさ」逆転現象およびスポット光源「範囲」不連続ジャンプ不具合の修正**
  - **ホスト `CameraLight64`（`aviutl2.exe` 内部構造体）フィールド仕様の厳密整合**：
    - `float[1..3]` が被照射点→光源への単位ベクトル `L = normalize(P_light - P_target)`（光線進行方向は `-float[1..3]`）であることを反映し、スポット光源・平行光源の射出向きが逆転していた問題を修正。
    - `float[15]` がスポット内錐半角ラジアン `範囲 * pi / 180`（`0..pi/2`）であることを反映し、従来の `acos(f[15])` 誤適用および `範囲 > 57.3°`（`1 rad` 超）や `< 2.9°` でフォールバック角へ急変していた不連続ジャンプを根治。公式 `obj.getvalue` でスポット光源の `ぼかし`・点／スポット光源の `減衰` も取得し、`0°..90°` 全域で連続変化（`明るさ = 0%` またはスポット `範囲 + ぼかし = 0°` 時は完全消灯）するよう修正。
    - 仮想開口を従来の `120px` 先の正方形パッチから `3px` 先のアンチエイリアス円形／放射状開口へ変更し、狭角スポット時の根元 `120px` 空白ギャップと四角形断面アーティファクトを解消。
  - **点光源・スポット光源・平行光源すべてで「明るさ」を上げるほど体積光が暗くなっていた逆転現象の根治**：
    - AviUtl2 ホスト 3D OIT シェーダー（`Shader #118`）がスライス多角形へ `unlit_mul + amb + cl_rgb * Cone * Atten * max(0, N·L)`（`unlit_mul = clamp(1 - 明るさ/100, 0, 1)`）を乗算する仕様に対し、公式 `obj.drawpoly({x,y,z,u,v,vx,vy,vz}, 4, alpha)` の頂点法線指定（点・スポット光源では光源投影点基準の適応共有ノード格子により全スライスで `N·L ≈ 1.0` を維持）と `beamatlas` 内のピクセル単位 RGB ホスト照明補償を導入し、`0%..200%` 全域で明るさに正比例して単調増加（`100%` 超の高輝度領域も自然に増光）するよう修正。
