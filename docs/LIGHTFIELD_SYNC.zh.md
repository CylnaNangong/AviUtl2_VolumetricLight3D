# `VL3DLF v3` 跨脚本共享真 3D 光场与遮挡阴影协议（`VolumetricLight3D v3.16` × `Snow3D v1.23`）

本文档说明 `VolumetricLight3D.obj2 v3.16+` 与 `雪（3D）.obj2 v1.23+`（以及后续任意第三方 3D 粒子/物体脚本）之间共享真实三维光场与遮挡阴影的架构设计、二进制布局与光学模型。

---

## 1. 设计目标与约束

1. **真三维空间与真三维阴影（“能够被照亮 + 被遮挡就不亮”）**：
   - 雪花不仅在二维投影落在光束上时发亮，而是必须在**三维空间 $(x, y, z)$** 内真正落入体积光锥/光柱（支持平行光 `kind=0`、点光源发散光 `kind=1`、汇聚光 `kind=2` 及相机控制 3D 聚光灯 `ltype=4/5`），并吸收对应光线起点的彩绘玻璃局部颜色。
   - 当三维空间中某条体积光线在到达雪花前被 **3D 模型（`.obj` / `.vrm`）或 2D 图层遮挡物**截断（$t_{\text{ray}} > t_{\text{occ}}$）时——哪怕从摄像机二维视角看该雪花完全没有被遮挡物挡住——落入该三维阴影柱内的雪花也必须**自动熄灭不发光**。
   - 在 `occ_mode = 2 / 3`（前景遮罩模式）下，位于前景人物背后（$z_{\text{cam}}(\text{snow}) > z_{\text{cam}}(\text{fg})$）的受光光晕自动消隐，位于前景人物前方的雪花则正常发光。
2. **零额外缓存预算、零插件依赖、宿主桥接 100% 安全**：
   - `VolumetricLight3D` 在 `beamatlas` 覆写 `"object"` 为 `1×1` 前，复用 `"object"` 缓冲（最大 `48×114` = `5,472` 像素）单次运行 `ps_vl_lfpack`，峰值 `cache:*` 像素增量严格为 **`+0`**。
   - 跨脚本通信仅使用 AviUtl ExEdit2 官方公开的 `global` 共享表，且所有载荷统一封装为纯 7-bit 可打印 ASCII Base64（前缀 `"VL3DB64:"`），**不含任何 `\0` 字节**，彻底杜绝宿主 C++ 层 `lua_tostring` / `lua_pushstring` / `c_str()` 截断风险。
   - `Snow3D v1.23` 保持 100% 纯脚本零 `.aux2` 插件依赖；当场景中不存在活动体积光时零额外绘制、与 `v1.22` 逐像素完全一致。

## 2. `global` 键空间与生命周期

| 键名格式 | 示例 | 说明 |
|---|---|---|
| `VL3D_LF_IDX:<scene_id>` | `"3,6"` | 当前场景（主合成 `0`，子场景 `1..N`）已注册的活动体积光图层号升序逗号列表；无活动光源时为 `""` |
| `VL3D_LF:<scene_id>:<layer>` | `"VL3DB64:VkwzRE..."` | 指定场景与图层发布的 `VL3DLF v3` 光场数据包（撤回时置为 `""`） |

- **子场景隔离**：所有键均以 `scene_id` 分区，子场景内的体积光不会串入主合成或其他子场景。
- **帧新鲜度校验**：包头记录场景绝对帧号 `scene_frame = frame_s + frame`；接收端仅接受 `|cur_scene_frame - sframe| <= 1` 的槽位（既兼容 `体积光` 图层编号小于 `雪（3D）` 的同帧零延迟读取，也兼容相反图层顺序的播放帧衔接，同时防止时间轴跳转后残留旧光场）。
- **即时撤回（`vl_lf_withdraw`）**：当 `intensity == 0`、`length <= 0.5`、`obj.alpha <= 0` 或光源图层为空提前短路时，立即清空对应槽位并从索引移除。
- **查询约定（禁止 `pairs(global)`）**：AviUtl2 宿主的 `global` 代理对象未挂载 `__pairs` 元方法，调用 `pairs(global)` 会触发运行时异常；所有接收端必须先按名读取 `global["VL3D_LF_IDX:" .. tostring(scene_id)]`，再按槽位号逐一索引 `global["VL3D_LF:<scene_id>:<layer>"]`。

## 3. `VL3DLF\3\0` 二进制包结构（Base64 解码后）

解码 `"VL3DB64:"` 后的字节流总长度为 `320` 字节扩展头（当 `flags` bit 9 = `512` 置位时；兼容旧版 `264` 字节固定头）+ 按需附加的最多 3 个 RGBA8 图像带（`9,536` ～ `22,000` 字节）：

### 3.1 包头（`320` Bytes / 兼容 `264` Bytes，小端序）

- **`offset 0..7`（`char[8]`）**：魔数 `"VL3DLF\3\0"`
- **`offset 8..39`（`int32_t[8]`）**：
  - `i32[0]`：`scene_id`
  - `i32[1]`：`layer`（发布者所在图层号）
  - `i32[2]`：`scene_frame`（场景绝对帧号）
  - `i32[3]`：`rendering_id`
  - `i32[4]`：`mode_kind`（`0` = 平行光，`1` = 发散点光源/聚光锥，`2` = 汇聚光）
  - `i32[5]`：`flags` 位掩码（`1` = 含 Band 0 辐射场，`2` = 含 Band 1 投射阴影深度场，`4` = 含 Band 2 相机前景深度场，`8` = 相机 3D 聚光灯包络，`16` = 3D 大气雾调制开启，`32` = `occ_3d_mode == 1` 物理前后遮挡，`64` = 正交/无精确编辑相机回退，`128` = 存在活动宿主 3D 摄像机光源，`256` = 主 3D 摄像机光源为点/聚光源，`512` = 含 `320` 字节扩展实时相机基底与 `host_unlit_max`）
  - `i32[6]`：`rad_w`（`48`）
  - `i32[7]`：`sh_w`（含阴影带时为 `48`，否则 `0`）
- **`offset 40..263`（`float[56]`）**：
  - `0..11`：光源平面中心 `W0(wx,wy,wz)` 与正交基 `Wr`、`Wd`、`Wn`
  - `12..21`：`S_or_U`、`inv_2Hx`、`inv_2Hy`、`dS_wn`、`u_wn`、`L_tot`、`k_dec`、`inv_end`
  - `22..29`：有效发光包围框 `u0_b..v1_b` 与阴影采样域 `su0..sv1`（`[-0.04, 1.04]`）
  - `30..38`：全局辐射增益 `gain_rgb` 与世界空间快速裁剪包围盒 `aabb_min` / `aabb_max`
  - `39..47`：3D 聚光灯顶点 `cl_p`、光轴 `cl_d`、`cos_in_sp`、`cos_out_sp`、距离衰减 `att_k_sp`
  - `48..55`：`cam_zmax`、`z_win_cam`、阴影软边宽度 `sh_soft_t`、3D 雾强 `fog_amt`、`inv_fscale` 与风场偏移 `wox..woz`
- **`offset 264..319`（`float[14]`，`flags & 512 != 0` 时存在）**：
  - `56..68`：当前帧真实渲染相机位置 `cam_x..z`、正交基 `f_x..z` / `r_x..z` / `d_x..z` 及焦距 `focal_d`（供 `camera_mode == 2` 编辑自由相机模式下无插件粒子脚本同步实时视角）
  - `69`：`host_unlit_max`（宿主 3D 光照在光锥外/背光面的亮度上界 `unlit + max(amb_rgb)`，无 3D 相机光时为 `1.0`）

### 3.2 像素数据带（RGBA8）

1. **Band 0（`48 × 48 × 4 = 9,216` Bytes）**：阈值过滤并乘算光色后的光源局部辐射亮度 `(R, G, B, coverage)`。
2. **Band 1（可选，`48 × 48 × 4 = 9,216` Bytes）**：统一融合 3D 网格阴影图（`g_shmap`）与最多 8 层 2D 遮挡平面光线求交（`g_occ`）后的归一化首次遮挡距离 `tn = clamp(t_occ / L_tot, 0, 1)`，以 16-bit 无损拆分为 `R = hi8, G = lo8`，`B = occ_coverage`，`A = valid`。
3. **Band 2（可选，`48 × 18 × 4 = 3,456` Bytes）**：统一融合 3D 模型相机深度图（`g_camocc`）与 2D 前景剪影平面视向深度的归一化前景深度 `zn = clamp(z_fg / cam_zmax, 0, 1)`（`R = hi8, G = lo8, B = fg_coverage, A = valid`）。

## 4. 推荐图层摆放顺序

在 AviUtl ExEdit2 时间轴中建议按以下从上到下（小编号到大编号）顺序摆放，使同帧内 `体积光（3D）` 先发布最新光场、`雪（3D）` 同帧零延迟读取：

1. **Layer 1**：光源图层（如彩绘玻璃窗、发光标题、光口图形；若使用相机 3D 聚光灯可省略）
2. **Layer 2**：遮挡物图层（`.obj` / `.vrm` 3D 模型，或 2D 人物立绘 / 窗框剪影）
3. **Layer 3**：`体积光（3D）v3.16`（开启前景遮挡 `3D影＋前景マスク(推奨)`）
4. **Layer 4**：`雪（3D）v1.23`（展开「体积光联动」，默认自动开启「受体积光照亮」）
