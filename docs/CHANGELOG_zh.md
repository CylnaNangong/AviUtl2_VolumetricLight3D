# 更新历史 — 体积光（3D） / VL3DBridge

## v3.14（2026-10-28）
- **修复非聚光源路径（2D 图层 / 点光源 / 平行光）光束整体亮度较 v3.06（README 演示动图版本）低约 4%～9% 的问题**
  - **根因定位**：`v3.08` 为根治聚光锥 WBOIT 年轮环引入的「比例 Alpha 编码」（`wboit_ka = 0.24`）连同着色器内 `ka_eff = max(0.24, min_a*2.4/core_emit)` 提升项，使非聚光路径的逐切片输出 alpha 与发光量成正比；数字孪生（`analysis/beam_brightness_twin.py`，CPU 复刻各版本 `beamatlas` 输出级 + 宿主 Shader #118 / OIT 合成）实测切片栈总不透明度（veil）达 `0.198`，约为 v3.06 常量 alpha 令牌（`0.096`）的 2 倍。多出的不透明度在宿主 OIT 合成中既自衰减深处切片、又额外遮蔽光束下的背景，表现为光束整体变暗（黑底约 −4.5%，亮背景上像素值最多 −0.075）。
  - **当初为何引入**：比例 Alpha 的目的是在宿主 WBOIT 深度权重下保持全切片 Straight 色比 `r4.rgb / r4.w` 恒定，以根治聚光锥的「年轮锯齿环」与灰色烟雾 veil（见 v3.08 / v3.09 条目）；但聚光源路径自 `v3.12` 起已改回「常量 alpha + 色比颜色」（`wboit_ka = 0`、`min_opt_a = 4/255`），非聚光路径成为唯一仍使用 v3.08 比例 Alpha 的分支。
  - **修复**：非聚光路径恢复常量 alpha 令牌（`wboit_ka = 0` → 着色器内 `out_a = p12.z`），与 v3.06 及 v3.12+ 聚光路径对齐；数字孪生验证亮度比恢复至 v3.06 的 `0.95～1.00×`（修复前 `0.91～0.96×`），veil 回到 v3.06 水平，且不影响 v3.09～v3.12 的任何聚光修复。回退仅需一行 `wboit_ka = 0.24`。
  - **复现与验证**：`python3 analysis/beam_brightness_twin.py`（无需 GPU / AviUtl2，输出各版本亮度比、背景耦合与消融表）。
- **说明（非回归、属预期行为）**：`v3.07` 引入的逐像素宿主照明逆补偿含 `saturate(1/H)` 截断：当场景宿主照明 `H > 1`（摄像机控制「发光度」> 100% 或存在环境光/多灯）时，光束被限定在设计辐射亮度；而 v3.06 会额外乘上 `H` 因而更亮。若旧工程发光度 > 100%，新版本会显得暗 `1/H` —— 如需旧观感请将发光度调回 100% 或按比例上调「强度」。

## v3.12（2026-10-26）
- **彻底根治「聚光源（摄像机）」移至左侧（`X < 0`）并勾选「添加阴影」时光束内部出现的横条纹黑斑问题**
  - **根因定位**：「画面状态显示（HUD）」的 4 行文字公告板原先以 `alpha = 0.92`（跨过宿主阴影投射 Alpha 测试阈值 `>= 0.5`）放置在 3D 世界空间的 `cam + f × focal_d - r × 420 - d × 400` 处（`z_cam = focal_d = 1024`，例如俯瞰编辑视角下位于世界坐标约 `(-420, -704, -445)`）。当聚光源移至左上方（`X <= -720`）且开启「添加阴影」（`ltype = 5`）时，这块悬浮在场景半空的 HUD 文字板恰好切入聚光圆锥（外半角 `范围 + 0.5×模糊`），将其 4 行文字剪影写入宿主阴影贴图，并在后方体积光切片上投射出横条状暗斑（而 `X >= 0` 或关闭「添加阴影」时均不发生阴影相交）。
  - **近裁剪面微缩投影（`z_cam = 32`）**：在 3D 透视相机下，保持 HUD 与提示文字在屏幕上的像素位置与字号 100% 不变，将其等比微缩贴合至相机镜头前方近平面 `z_cam = 32`（`k_hud = min(1, 32 / focal_d)`，`zoom = k_hud`）。由于 `z_cam(HUD) = 32 << z_cam(Light)`，场景内任意光源穿过 HUD 的阴影射线均射向相机后方（视锥体外），在几何拓扑上与体积光切片彻底隔离，同时一并解决了近景 3D 模型（`z_cam < 1024`）遮挡 HUD 文字的问题。
- **彻底根治聚光源正投及斜投光锥（如 `X = +1110 / -990`）内部残留的空心马蹄形（`∩` 形）亮弧、细微黑点与斜向末端弧形折线**
  - **4 阶基准不透明度（`min_opt_a = 4/255`，`poly_alpha = 0.064125`）与切片相干存活机制**：`v3.11`（`min_opt_a = 1/255`，`poly_alpha = 0.2565`）下 `scaled_sp × 255` 落在最低 1 阶量化阈值（`0.6～1.3`）附近；当 `scaled_sp × 255 < 1.0` 时，2D R2 空间抖动会将部分纹素置为 `(0,0,0,0)`，经硬件 `2×2` 双线性采样后把相邻 3 颗有效纹素的 `r4.w` 一并拉低至 `0.75 × 0.001006 < 0.001` 触发整片 `discard`（存活率由线性 `p` 骤降为 `p⁴`），导致仅两侧半影带 `[R - B/2, R + B/2]`（因 `1 / h_est` 放大保持 `>= 1.0`）与峰值距离段维持 `p⁴ = 1`，围成空心马蹄形亮弧与散点黑孔。`v3.12` 在严格维持外缘零邻域 `r4.w = 0.001006` 硬件级截断的同时将内部灰阶精度提升 4 倍以彻底消除 `p⁴` 断崖与颗粒黑孔，并在极低亮度区（`s255 < 4`）自动切换为黄金比切片相干存活 + `C_slice >= H_host` 色比保底，确保任意亮度下白色地面绝不发灰变暗（保持 `255/255` 纯白）。
  - **解析「相机视线 ∩ 聚光圆锥 ∩ 终端球面 `L_tot` ∩ 前景遮挡面」6 点弦积分**：斜向投射时，同一条相机视线上近端光锥前壁的传播距离 `||wp - LP||` 比深处核心更早跨入「光束长度」衰减区，逐切片局地求值会使宿主陡峭的 `w(z) = exp(-0.085z)` 深度权重锁定前壁衰减值，在斜光束中段印出弧形明暗折线。现改为对视线在「圆锥 ∩ 球 `L_tot` ∩ 前景遮挡面」解析弦区间 `[s_c0, s_c1]` 上执行 6 点中点积分统一求取轴向衰减、距离衰减与角度包络（并移除 `shell_cull`），令同一视线上所有切片的 Straight 色比 `r4.rgb / r4.w` 完全一致，彻底抵消 WBOIT 前壁深度偏置（同步修正正交回退下 2D 前景遮罩视线方向 `-p8` → `-p2`；点光源、平行光与 2D 图层光源路径保持不变）。

## v3.10（2026-10-26）
- **彻底根治「聚光源（摄像机控制）」光锥内部残留的瓦片状切片段差与 3D 阴影侧壁阶梯锯齿**

- **修复首次打开工程时日志「初始化完成（耗时 0.00 秒）」恒为 `0.00 秒` 的计时基准跳变问题**
