# 更新历史 — 体积光（3D） / VL3DBridge

## v3.06（2026-10-24）
- **修复特定图层构成下前景遮挡阴影呈「矩形黑块 / 边缘破碎 / 闪烁」的问题**
  - 新增遮挡蒙版「剪影审计」`audit_object_alpha()`：当带效果加载（`obj.load("layer", no, true)`，官方文档标注效果侧绘制时可能异常）返回近乎全不透明矩形（α 覆盖率 ≥ 98.5%）时，自动回退无效果原始加载并择优采用，消除矩形黑块阴影；审计经 `getpixeldata` 稀疏采样（≤64×64 点）实现，`pcall` 全防护且不支持环境自动跳过。
  - HUD 自诊断：遮挡栏新增 `,opq`（遮罩近乎全不透明）与 `L4*`（已回退原始加载）标记，方便定位缺少 Alpha 通道的遮挡素材。
  - `occ2d` 拖拽缓存键加入加载模式（fx/raw）并在恢复前回填，杜绝误恢复旧蒙版导致的闪烁。
  - 14 段 HLSL 着色器 0 改动（字节级一致）；健康图层渲染结果与 `v3.05` 逐像素一致（`max_rgba_diff=0`，`frame_s=0` 与 `frame_s=619` 双工况验证）。

## v3.05（2026-10-24）
- **修复非零起始帧片段与嵌套次合成下前景遮挡 `0hit` 问题**
  - 引入基于官方 API `obj.frame_s + obj.frame`（转场尾部按 `obj.frame_e` 安全钳制）的场景时间轴帧计算函数 `vl_scene_frame()`，修复当「体积光（3D）」片段未从时间轴第 0 帧开始（`obj.frame_s > 0`）时，因将局部帧 `obj.frame` 传给 `VL3DBridge` / `.aup2` 查询空白区间而把前方图层误判为 `"EMPTY"`（`遮挡=0hit`）的问题（同步覆盖前景遮挡、「前景融入背景」、文本光源对齐补偿、场景摄像机与水面颜色读取）。
  - 新增 `obj.scene_id` 跨场景校验与内置「文本」对象 18 种文字对齐的官方 `obj.getvalue(layer, ...)` 直读回退，确保在主合成预览/导出嵌套次合成（`シーン` 对象）及无插件 `ScriptOnly` 模式下前景遮挡与文字投影同样 100% 准确命中。

## v3.04（2026-10-24）
- **修复实机 `D3DCompile` 警告升格错误（`X3129` / `X3556`）**
  - 针对 AviUtl ExEdit2 宿主 `Media::ShaderCompile::compileFromMemory()` 默认启用 `D3DCOMPILE_WARNINGS_ARE_ERRORS` 的特性，将 `ps_vl_pool` 与 `ps_vl_prep` 分层步进中的有符号整数除法（`/ 32`、`/ 16`）替换为精确等价的二的负幂浮点乘法上取整（`ceil(p0.z * 0.03125)`、`ceil(p0.z * 0.0625)`），根治实机加载像素着色器时触发 `X3556 -> X3129` 编译报错的问题。

## v3.02（2026-10-24）
- **工程/次合成首次打开实时初始化日志提示**
  - 首次打开含体积光的工程或首次展开次合成时，立即在日志窗口输出四语自适应的「初始化中……」与首帧完成后的「初始化完成（耗时 X.XX 秒）」，避免首帧加载大图与管线初始化黑屏期间被误认为卡死（每个场景/图层仅提示一次）。
- **8K UHD（7680×4320）画幅与 16K（16384px）超巨幅素材加固**
  - 为 `ps_vl_pool` / `ps_vl_prep` 引入自适应分层步进采样，确保极端长宽比或 16K 贴图下中间缓存恒不超过 D3D11 RTV 上限（`4096px`）与 `1,600` 万像素缓存池预算。
  - 自定义对象光源回退捕获优先使用 `"tempbuffer"`，避免高分辨率画幅额外占用 `cache:*` 额度。

## v3.01（2026-10-24）
- **超高分辨率光源 + 2D 前景遮挡缓存保护修复**
  - 移除 `vl_bf_mip()` 完成后不再需要的原尺寸 `"object"` 备份缓存并在 Mip 生成后立即将 `"object"` 缩至 `4×4`，根治 4K/6K 以上大图触发 `TemporaryImageCacheSize`（`1,600` 万像素）LRU 驱逐导致的光束纯蓝化问题。
  - 为 2D 遮挡图集与「前景融入背景」输入/环境降采样缓存增设安全尺寸上限（`<= 2048px` / `<= 512×288`）。

## v3.00（2026-10-24）
- **`VL3DBridge.aux2`（v1.21）架构正式整合**
  - 正式合入无锁只读桥接 + Direct3D 11 ComputeShader（`cs_5_0`）GPU 硬件 3D 阴影/深度光栅化、受限 Lua 环境（`os == nil` / `io == nil`）兼容，以及 `テキスト` 全部 18 种文字对齐与 7 种文字装饰的中心偏移精准对齐。
- **新增「前景融入背景（`前景なじませ`）」子系统（AutoBlendLight 3D 联动）**
  - 基于 nctype 氏 `AutoBlendLight v1.3.3`（MIT License）深度整合，支持自动或按图层区间选定前方 2D 图层，使其自然融入背景色调与 3D 体积光方向/亮度环境（默认关闭，自动保护更靠前的非目标字幕/UI 与 3D 模型）。
