# 雪（3D）与体积光联动：初步设计记录

> **状态：调研草案，功能尚未实现。** 本文不把离线模拟当作 AviUtl2 真机结果；也不假定不同对象按图层顺序同步求值。雪 3D 检查基于 `CylnaNangong/AviUtl2_Snow3D` 的 `62c8a9eb589652de155ae9eaf7488bd9d559aaa7`。

## 已确认的数据路径

- 体积光 `src/VolumetricLight3D/modules/19_render.lua` 每批最多 64 个切片，将光源 mip、前景遮挡和阴影图传给 `beamatlas`，再将生成的二维图集贴到 3D 多边形。`object` 缓冲区在下一批会被覆盖。着色器还包含相机/合成相关补偿，输出不宜直接当作物理入射辐照度。
- 雪 3D 当前脚本先在 Lua 构造 `parts`，纹理模式按深度和 alpha 分桶后调用 `obj.drawpoly`；纹理读取失败时才使用带顶点色的三角形回退。不能假设已有可采样 3D 纹理的粒子 Compute Shader，也不能只改回退路径。
- `VL3DBridge` 已注册脚本模块；随仓库保存的 SDK 头文件暴露 `EDIT_HANDLE::get_direct3d_device()`（v2.1.15）和脚本模块参数中的 `edit`。这并不自动提供脚本缓冲区的 D3D 资源指针，也不保证跨对象的执行顺序或 GPU 同步。
- [Lua 文档](https://docs.aviutl2.jp/lua/) 描述了缓冲区、着色器及脚本接口；[首页](https://docs.aviutl2.jp/) 说明内部图像为预乘 alpha 的 RGBA16bitFloat。发布前仍需对照完整官方 SDK 与宿主验证具体生命周期及线程契约。

## 建议的方向与不可跳过的问题

1. 定义独立于屏幕合成的光场语义：世界空间某点的线性 RGB 入射光（含光源图案、距离衰减与可用的遮挡），不把切片的 WBOIT alpha、相机补偿或已经积分的屏幕颜色当作粒子光照。无光源和范围外返回零；多个光源使用明确的线性加和和强度限制。方向性散射若没有入射方向数据，不能声称实现了真实相位函数。
2. 在与现有 `beamatlas` 相同的投影、阈值和遮挡语义下计算该字段，避免为体积光和粒子各维护一套不一致的公式。体素网格可以是实现手段，但 `Texture3D` 本身不会解决从脚本缓冲区获取彩色光源及遮挡图的问题；必须先验证官方支持的数据传递方式及成本。32×32×64 的 RGBA16F 网格约 512 KiB，64×64×128 约 4 MiB，未计多光源、临时缓冲与同步。
3. 对外接口应批量输入粒子世界坐标并返回线性 RGB，而非逐粒子同步 GPU 读回。三线性采样要明确体素中心、边界和网格外的零值；粒子局部到世界坐标需覆盖对象缩放、旋转及中心偏移，且使用折返后的实际绘制位置。上述 GPU→CPU 路径需要评估 staging/readback 同步成本；不能把 GPU 资源指针当成可在 Lua 中直接采样的数据。
4. 必须先证明雪消费的是**同一渲染上下文、同一场景、同一帧及当前参数**的光场。预览拖动、随机帧、嵌套场景、同帧编辑参数、缓存命中、多实例、多线程和导出均可能破坏“最近一次写入”的假设。仅帧号与场景号 不足以保证缓存有效；若不能获得可靠的求值身份和依赖顺序，应使用显式可重建的数据源/依赖，或安全回退到原雪色，不得读取旧帧。清缓存、对象删除和插件退出均需释放资源。
5. 雪仓库需要增加可选联动与绘制策略：现有纹理模式的一个批次共享纹理和 alpha，不能简单将 RGB 写进不存在的顶点色字段。需要验证宿主支持的纹理着色方式，例如按颜色量化分桶及生成对应颜色纹理，并控制批次数、深度排序和预乘 alpha；回退三角形也要应用相同光照。禁用联动、模块缺失、旧宿主或采样失败时必须保持原有雪效果。

## 测试工程与验收

提供的文本工程包含 2048×1080、30 fps 的彩窗背景和人物前景场景，彩窗位于 Z=2050、人物 Z=1220；该场景的体积光参数为平行光、长度 2322、方向 90°、手前角度 63.8°。这可作为视觉参考，但雪联动需要在同一场景另加雪对象；Windows 绝对素材路径、外部字体/插件等需在真机重新关联。

- 单元：三线性插值的中心/边界/范围外，变换与折返，多光源和零输入；缓存身份及失效；色彩与 alpha 范围。
- 离线集成：彩色图案内外、不同深度、遮挡前后、光强为零、无桥接模块、不同对象变换和多光源；针对纹理与回退两种绘制路径分别验证。
- Windows 真机：AviUtl2 2.1.15+，前后调整两个对象、相机运镜、拖动时间轴、连续和随机帧导出、编辑同帧参数、子场景、多实例、缓存清除，以及 CPU/GPU 时间和资源释放。与未开启联动逐帧对照，确认无过期闪烁和无关场景串光。
